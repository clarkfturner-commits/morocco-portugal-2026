# Morocco & Portugal · Nov 2026

Shared trip planner for three families. Built with React, Vite, and Firebase.

## Features

- Per-family private spaces (itinerary, flights, expenses, packing, notes)
- Shared space (group itinerary, shared expenses with auto-balance, meetups, wishlist, photos, group packing, shared notes)
- Live countdown to departure
- Real-time sync across all devices
- No login required — anyone with the link can edit

## Setup

See `DEPLOY_GUIDE.md` for full step-by-step instructions.

Short version:
1. Create a Firebase project, get config keys
2. Push this code to GitHub
3. Deploy to Vercel
4. Share the URL

Total cost: $0.

## Local development (optional)

If you want to test locally before deploying:

```
npm install
npm run dev
```

Then open http://localhost:5173.

## Tech stack

- React 18 + Vite
- Tailwind CSS
- Firebase Firestore (real-time database)
- Lucide icons
- Cormorant Garamond + Outfit fonts
